# Sales Data Analysis & Forecasting

## Project Overview

This project analyzes historical sales data to identify
sales trends, product performance, regional performance,
and patterns that can support business decision-making.

The project demonstrates data cleaning, exploratory data
analysis, SQL analysis, data visualization, and basic
sales forecasting using Python.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Statistical Analysis
- Data Visualization

## Analysis Performed

### Data Cleaning
- Checked missing values
- Removed duplicate records
- Validated sales values
- Validated quantity values
- Converted date fields

### Exploratory Data Analysis

Analyzed:

- Total sales
- Average order value
- Regional sales
- Product performance
- Category performance
- Monthly sales trends

### SQL Analysis

SQL queries were used for:

- Aggregation
- Filtering
- Grouping
- Sorting
- Sales analysis

### Visualization

Created visualizations for:

- Monthly sales trends
- Sales by region
- Top products

### Forecasting

A simple moving-average approach was used
to estimate sales for the following month.
